# ai-financial-tracker
AI-powered personal financial health and expense tracking application with ML-based categorization, predictive budgeting, anomaly detection, financial goals, investment tracking, and privacy-first architecture.
## Development Workflow

This project follows a structured development workflow using Git and GitHub.

- `main` contains stable project code.
- Each major module is developed on a separate feature branch.
- Changes are committed using Conventional Commit messages.
- Completed module work is merged into `main` after verification.
